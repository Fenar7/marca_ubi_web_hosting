## 1. Executive Summary & Problem Resolution

Based on user feedback on the previous visual output (`Screenshot 2026-11-16 143237.png` and `Screenshot 2026-11-16 143255.png`), three critical deficiencies were diagnosed and resolved to achieve 1:1 fidelity with the reference fintech archetypes (**Fundora**, **Finlo Flash**, and **Recover**):

1. **Swiss Thin Typography (`HelveticaNeue-Light` / 300 Weight)**:
   - *Problem:* Hero valuations (`₹ 65,40,000`) were rendered in heavy `Circular XX` 700 bold weight, clashing with the airy, refined aesthetic seen in the Fundora reference.
   - *Resolution:* Switched to the project's existing Swiss font family via `--font-helvetica-neue` (`font-weight: 300; letter-spacing: -0.035em; line-height: 1.1; font-variant-numeric: tabular-nums lining-nums; font-feature-settings: "tnum" 1, "lnum" 1;`). Applied consistently to both `CommercialVelocityBarChart` and `PipelineDonutChart`.

2. **100% Fully Functional Interactive Dropdowns**:
   - *Problem:* Controls with chevron indicators (e.g. `Last 30 Days ▾` and `By Category ▾`) were previously rendered as static `<span>` elements with hover styles, creating a deceptive UI affordance.
   - *Resolution:* Replaced with fully accessible, production-grade dropdown systems:
     - **Timeframe Selector (`CommercialVelocityBarChart`)**: `<button type="button" aria-haspopup="listbox" aria-expanded={isTimeframeOpen}>` with outside-click dismissal (`mousedown` listener), escape key handling, and reactive URL synchronization via `router.push('/admin?timeframe=' + slug)` wrapped in React 19 `startTransition`. Options: `Last 7 Days`, `Last 30 Days`, `Last 90 Days`, `This Quarter`, `This Year`.
     - **Breakdown Perspective Selector (`PipelineDonutChart`)**: `<button type="button" aria-haspopup="listbox" aria-expanded={isViewModeOpen}>` with outside-click listener and instant client-side perspective toggling between:
       - `By Category`: Service line distribution (Advisory, Brand Strategy, Design Systems, etc.)
       - `By Stage`: Pipeline funnel progression (Discovery, Proposal, Negotiation, Won)
       - `By Deal Size`: Capital tier classification (Enterprise >₹25L, Mid-Market ₹10L–25L, Growth ₹5L–10L, Starter <₹5L)

3. **Fundora 1:1 Parity Polish**:
   - *Floating White Card Tooltip:* Replaced the dark obsidian tooltip with Fundora's crisp white card (`background: #ffffff; color: #111111; border: 1px solid #e7e7e4; box-shadow: 0 4px 18px -2px rgba(0, 0, 0, 0.08);`).
   - *Vertical Dashed Stem Line:* Added SVG connecting stem line (`stroke: var(--admin-accent-brand, #ea002a); stroke-width: 1px; stroke-dasharray: 2 2; opacity: 0.65;`) connecting the active column's apex beacon circle down to the floating white card.
   - *De-duplicated Right Card Hierarchy:* Excised the redundant horizontal legend above the progress bar in `PipelineDonutChart`, matching Fundora's clean hierarchy: Title -> Thin Valuation + Active Deals Badge -> Subtitle -> Continuous 14px Capsule Progress Bar -> Ranked Hairline Detail Rows.
