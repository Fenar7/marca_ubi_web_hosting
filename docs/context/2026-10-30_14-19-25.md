This context register captures the full state, findings, and resolutions across two primary architectural domains:

1. **Header Slot Machine Ticker (Pentagram-Style) Realignment & Visibility Fix**:

## 2. Root Cause Analysis (Deep Dive)

### Issue A: Pentagram Header Empty Slots (`ClientHeader`)
* **File:** `src/app/components/ClientHeader/ClientHeader.module.scss` & `ClientHeader.tsx`
* **Root Mechanism:**
  - `.streamAperture` had `height: 24px; line-height: 24px; overflow: hidden;` and `display: inline-flex; align-items: center; justify-content: center;`.
  - Inside `.streamAperture`, the vertical ticker track (`.streamTrack`) contains 14 items (each 24px tall, total height = $14 \times 24\text{px} = 336\text{px}$).
  - Because `.streamAperture` had `align-items: center`, the browser vertically centered the entire 336px column inside the 24px aperture.
  - This pushed the top of `.streamTrack` up by:
    $$\frac{24\text{px} - 336\text{px}}{2} = -156\text{px}$$
  - At GSAP $y = 0$, item 0 was positioned far above the visible clipping rectangle, causing the 24px window to land in an empty gap between items or outside the text bounds.
  - Furthermore, `.filterSentence` had `opacity: 0` unless `.streamVisible` was appended via `isScrolled`, leading to inconsistent visibility across rest and scrolled states.

### Issue B: Video Loading Latency (`BackgroundVideoEngine` & `ReelModal`)
* **Files:** `src/app/components/BackgroundVideo/BackgroundVideoEngine.tsx`, `BackgroundVideoEngine.module.css`, `ReelModal.tsx`
* **Root Mechanism:**
  1. **Missing MP4 FastStart (`moov` Atom at EOF):** Standard unoptimized MP4 exports place the `moov` (movie metadata index) atom at the end of the file after the `mdat` atom. The browser cannot decode or render frames without `moov`, forcing a multi-step HTTP Range request handshake (request byte 0 $\to$ detect missing index $\to$ request tail $\to$ parse index $\to$ request frames).
  2. **Next.js Dev Server Overhead:** In local development on Windows, Node.js single-threaded Range request chunking introduces 2–4 seconds of serialization overhead.
  3. **Opacity 0 Gating Without a Poster:** `<video>` started at `opacity: 0` until `onCanPlay`. With no `poster` attribute on `<video>` and no underlying image fallback in normal mode, users stared at a **pure pitch-black screen** (`#000000`) during buffering.
  4. **`preload="auto"` Hydration Contention:** Aggressive preloading saturated network sockets and CPU decoding threads concurrently with Next.js JavaScript hydration and GSAP animation initialization.

## 3. Engineering Resolutions Implemented

### 1. Header Dual-Slot Ticker Fix
- **Vertical Top Alignment:**
  - Updated `.streamAperture` to `align-items: flex-start; justify-content: flex-start; position: relative; overflow: hidden; height: 24px;`.
  - Positioned `.streamTrack` at `position: absolute; top: 0; left: 0; width: 100%; display: flex; flex-direction: column; align-items: flex-start;`.
  - Item 0 now locks precisely to $y = 0$ with 0px offset.
- **Accurate Text Width Dynamic Morphing:**
  - Refined `getWidths()` in `ClientHeader.tsx` to measure `textSpan.getBoundingClientRect().width` plus a 6px safety padding, preventing text wrapping or clipped glyphs as items cycle.
- **Persistent Visibility:**
  - Added `styles.streamVisible` to `.filterSentence` permanently so the capabilities sentence station remains visible across both transparent rest state and floating glass capsule state.

### 2. 0ms Video Poster & Buffer Optimization
- **Instant Luxury Poster Layer (`.instantPosterBackground`):**
  - Added an immediate image layer (`/images/hero-image.png`) behind the video at $z\text{-index}: 0$.
  - Users see a pristine high-fidelity brand photograph at $0\text{ms}$ with zero black void.
  - When the video is ready, the poster smoothly crossfades out over 800ms while the video fades in.
- **Preload Tuning:**
  - Changed `preload="auto"` to `preload="metadata"` with immediate play intent, reducing bandwidth contention during React 19 hydration.
- **Multi-Event Ready Triggers:**
  - Bound `onLoadedData`, `onCanPlay`, and `onPlaying` simultaneously so the video unveils the microsecond initial frame decoding completes.
- **Reel Modal Synchronization:**
  - Applied matching `poster="/images/hero-image.png"` and `preload="metadata"` to `ReelModal.tsx` for immediate showreel opening.
