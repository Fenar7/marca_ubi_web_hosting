# Deals workspace rebuild hand-off

The Deals workspace was rebuilt on `redesign/crm-fundora-editorial-cockpit` for [PR #126](https://github.com/Fenar7/marca_ubi_web_hosting/pull/126). Its base is `redesign/crm-conyest-luxury-dashboard`. The PR remains open for manual review.

The route uses Circular XX and Graphik, a compact company-first Board, a semantic Table and a mobile record list. The toolbar shares URL filters and pagination between views. The stage picker navigates lanes, while Filters change the result set. Counts, financial totals and Table sorting describe the loaded result page.

Desktop card surfaces support dragging with a visible grip. The move menu covers narrow and touch layouts and provides a keyboard alternative. The browser regression uses real Chromium mouse input and stubbed writes.

Stage movement uses the existing authenticated actions and guarded forms. The Deals list excludes the expected amount from restricted selects and serializes an unavailable value in the restricted DTO. Verified fixture interactions and live verification limits are in the [delivery record](../sales_funnel/deals_workspace_rebuild_2026_11_23/DELIVERY.md).

Read the [approved plan](../sales_funnel/deals_workspace_rebuild_2026_11_23/REDESIGN_PLAN.md) for scope, and [browser evidence](../sales_funnel/deals_workspace_rebuild_2026_11_23/RESEARCH_AND_QA.md) for the test environment. The older dashboard and Leads hand-offs cover their respective routes.
