## 1. What this module is

`Ubi`, a deferred chat assistant mounted in the root layout beside `<SmoothScrollProvider>`. Server-
compiled `KnowledgeBase` (Sanity + the site's own component constants) → props → a client-only,
deterministic three-tier matcher. Answers are transcriptions of published content, never generations.
Its intake collects the same brief as `/start-project` and POSTs the same payload to the same live
ingest route; the long form was refactored so both surfaces read one shared option module and one
shared payload builder.

Files owned: `src/app/chat-pod/**` (22 modules), `src/app/lib/intake/**` (2), one line in
`src/app/layout.tsx`, four `ProjectForm` step files reduced to imports, `tests/unit/chatpod-*.test.ts`
(6 suites, 162 tests), `tests/e2e/chatpod.spec.ts` (19 gates), `tests/playwright.chatpod.config.ts`.

Naming drift to expect: §01 and §06 of the plan name the unit suites `normalise.test.ts`,
`match.test.ts`, `knowledge-source-coverage.test.ts`. They shipped as
`tests/unit/chatpod-{normalise,matcher,intent-resolution,intake-fsm,ingest-payload-parity,knowledge-coverage}.test.ts`
— the `chatpod-` prefix is what makes `npx tsx --test tests/unit/chatpod-*.test.ts` runnable as one set.

## 3. Rules this module learned the hard way

1. **`$client-accent-red` on the assistant bubble is 4.29:1.** The tint is only `rgba(0,0,0,0.035)`, and
   red text on it still fails AA. Any accent-coloured *text* must sit on pure white or on black.
2. **A CSS-module class name is not a test selector.** Classes hash
   (`ChatPod-module-scss-module__zdHzLa__chip`). Select by role, `aria-*` and the two stable ids
   `#mubi-pod-panel` / `[aria-controls="mubi-pod-panel"]`.
3. **Chip stagger + `animation-fill-mode: both` makes axe cry.** Each chip waits
   `--chip-index × 40ms` at opacity 0, so a scan taken during the entrance measures a frame of an
   animation. Wait for the resting state (`chipsAtRest`) before scanning.
4. **`FloatingExploreButton` is not mounted on this branch** — no layout or page imports it. The
   collision gate was therefore generalised to "no other pointer-enabled fixed control in the bottom
   band overlaps the launcher", which still catches a future remount.
5. **The last transcript paragraph is the visitor's echo, not the question.** Intake walkers must key
   the free-text branch off the composer `placeholder`, or a re-worded question silently mis-drives.
6. **Skipping an optional slot promotes its pair to required.** Pressing `Skip` on email sets
   `phoneRequired`; a scripted walk that assumed a phone chip would then hang. Answer free text before
   chips in any walk that has both.
7. **Dev server 3003 is the owner's.** Probe with `curl`, reuse, never kill, never rebind, and never run
   `npm run build` while it is up — `build` rewrites `.next` underneath it.
8. **`npx tsx --test` has no `it.each`.** Register cases in a `for` loop of `it()` calls.
9. **`window.scrollTo` works but Lenis owns the wheel.** Scroll-depth gates read `scrollDepthPct()`, and
   the scroll event re-arms the idle timer, which is exactly why the reading-past-halfway test passes.
10. **An `aria-label` on the launcher fails SC 2.5.3 no matter how you word it.** The name and the hint are
    two flex lines, so the visible text axe reads is `UbiClose` while any sane label says `Ubi Close` —
    `label-content-name-mismatch`, serious, on every route the pod mounts. Label from content and put only
    the disclosure in `.srOnly`; the rule then does not apply, and the measured name is
    `Ubi Ask the digital assistant for Marca Ubi`. The axe gate now includes
    `[aria-controls="mubi-pod-panel"]`, not just `#mubi-pod-panel`, so this cannot come back.
