### Part 1: Brutally Honest Architectural & Visual Audit

#### 1. Cohesive Design Failure: Tonal Dissonance & Visual Imbalance
- **The Obsidian "Black Hole" Effect**: Card 1 in the masthead is rendered in `#111111` with a radial gradient patch, sitting right next to three stark white cards. On sRGB monitors, `radial-gradient(circle at 90% 15%, rgba(234, 0, 42, 0.22) 0%, #111111 70%)` paints a hazy, washed-out pinkish-red blob on the top-right. This looks like an unstyled CSS bug rather than luxury illumination.
- **Elevation Fracture**: Placing one dark card beside three white cards breaks Gestalt continuity. Cards 2, 3, and 4 look secondary and neglected.
- **Brand Violation**: `DESIGN.md` explicitly mandates: *"This is a light interface. Do not use glowing status effects, decorative radar motifs, or a dashboard made from repeated equal cards."*

#### 2. The Two Visual Graphs: Mathematical & Rendering Disasters
- **Commercial Velocity Dual-Bar Chart (`CommercialVelocityBarChart.tsx`)**:
  1. *Identical Flat "Telephone Poles"*: In `CommercialVelocityBarChart.tsx`, line 42 divides `totalIntake` by `pointCount` (`baseIntakePerPoint = Math.round(totalIntake / pointCount)`). With ₹65.4L divided by 5 points, every single bar is assigned the exact same ₹13.08L value! The chart renders five identical, flat black bars with zero rhythm or variation.
  2. *Dropdown vs. X-Axis Mismatch*: The card header contains an unmanaged `<select>` hardcoded to `"Last 6 Months"`, but the X-axis plots five weekly intervals across 24 days (`16 Oct`, `22 Oct`, `28 Oct`, `3 Nov`, `9 Nov`) generated by the page-level `30d` timeframe.
  3. *Distorted 3px Realized Revenue Slivers*: Because realized revenue is zero, line 189 applies a defensive clamp: `Math.max(3, realizedHeight)`. This squashes the rounded pill geometry into an awkward 3px red sliver on the floor, looking like a broken CSS border.
  4. *70% Dead White Space*: With only 5 data points in a 525px SVG width, the 14px bars occupy barely 30% of each column slot. 70% of each column is dead white space.
- **Pipeline Donut Chart (`PipelineDonutChart.tsx`)**:
  1. *The ₹ 52.8 Lakh Mathematical Discrepancy*: The center hole displays `Total Value ₹ 65.4L` (aggregating all 39 active deals). However, the category slices and legend aggregate `data.records`, which is hard-capped to **`.limit(6)`** by the follow-up preview query (`₹ 12.6L` total):
     - Web & Digital: `60%  ₹ 7,50,000`
     - Full-Suite Advisory: `25%  ₹ 3,20,000`
     - UI/UX Design: `15%  ₹ 1,90,000`
     - Total: **₹ 12,60,000** ($12.6\text{L}$).
     - The missing **₹ 52,80,000** ($80.7\%$ of the pipeline) was excluded from the SQL read! This creates a glaring mathematical contradiction between the center number and the legend.
  2. *Choked 82px Inner Hole*: The 140px diameter donut with an 18px stroke constricts the inner aperture to 82px. The text `"TOTAL VALUE ₹ 65.4L"` is squeezed against the inner border, creating visual claustrophobia.
  3. *Unmotivated Colors*: Using generic emerald (`#059669`) and amber (`#d97706`) clashes with the Marca Ubi monochrome + red luxury brand identity.

#### 3. Commercial Deals Ledger: Glaring Bugs & Alarm Fatigue
- **The Overlapping Search Input Bug (`CommercialDealsLedger.tsx` & `.module.scss`)**:
  - The class `.srOnly` was **omitted from `CommercialDealsLedger.module.scss`**.
  - In `CommercialDealsLedger.tsx`, `<span className={styles.srOnly}>Search opportunities</span>` renders as normal visible text inside `<label className={styles.searchLabel}>`, which is positioned absolute at `left: 10px`.
  - The text `"Search opportunities"` is painted directly on top of the `<input>` placeholder `"Search deals, company, rep..."`, creating an unreadable visual overlap.
- **The "Red Sea" of False Panic**:
  - Because `page.tsx` default-selected the overdue follow-up queue, 100% of the 6 preview deals were past due.
  - Every single row screams `Overdue 34d`, `Overdue 33d`, etc., in bright red (`#ea002a`).
  - Furthermore, the `Negotiation` stage progress bar is painted alert red, signaling failure rather than high-value pipeline progress.
- **Typewriter Hyphen Progress Pips**:
  - The stage pips render as disjointed hyphens (`--- - 60%`).
- **Chunky Action Buttons**:
  - Every row features identical, heavy `[Advance →]` buttons accompanied by redundant `[↗]` external links, cluttering the table.

### Part 2: Comprehensive Architectural Redesign Plan V3

#### Phase 1: Fix Visual Hierarchy & Scorecard Elevation (Masthead)
- **Harmonize Scorecard Elevation**:
  - Unify all four scorecards onto an architectural white surface (`#ffffff`) with 12px radii, subtle hairline borders (`#e7e7e4`), and delicate drop shadows (`0 1px 3px rgba(0, 0, 0, 0.02), 0 8px 24px -4px rgba(0, 0, 0, 0.04)`).
  - Eliminate the hazy pink/red radial gradient on Card 1. If Card 1 is an anchor card, use a solid deep obsidian `#111111` with crisp white Circular XX typography and an authentic `#ea002a` pill, or align it with the clean white editorial aesthetic.
- **Typography Calibration**:
  - Restore **Circular XX Medium/Bold** for primary metrics and kickers (`font-weight: 550–600`).
  - Purge hardcoded fallback strings (`"39 Deals"`, `"36.0%"`, `"14.8 Days"`), rendering truthful empty/neutral states when zero.

#### Phase 2: Fix Data Aggregation & Chart Mathematics
- **Server-Side Category Aggregation in `page.tsx`**:
  - In `src/app/admin/lib/dashboardContracts.ts`, include `service_category` in the pipeline SQL select.
  - In `src/app/admin/(workspace)/page.tsx`, fold category totals across **all 39 active deals** (not just the 6 preview rows).
  - Pass the aggregated categories to `PipelineDonutChart` as `categories: { name: string; value: number; dealCount: number }[]`.
  - Result: Legend categories will sum exactly to **₹ 65,40,000**, matching the center label 100%.
- **Refined Donut Geometry**:
  - Increase SVG size to `180px × 180px`, radius $R = 64\text{px}$, stroke width $W = 12\text{px}$.
  - Expand inner hole to **116px** (+41.5% interior breathing room).
  - Add 2° angular segment separation gaps.
  - Align palette to Marca Ubi luxury tones: Obsidian `#111111`, Brand Red `#ea002a`, Slate `#71717a`, Platinum `#e4e4e7`.

#### Phase 3: Commercial Velocity Dual-Bar Chart Sync & Geometry
- **Wire Timeframe Controls**:
  - Synchronize the chart's timeframe selector with URL routing (`useRouter` / `startTransition`), sharing the same timeframe state as the masthead.
- **Eliminate Synthetic Division**:
  - Stop dividing `totalIntake / pointCount`. Aggregate actual lead creation timestamps (`leads.created_at`) within the timeframe intervals, reflecting true cadence momentum.
- **Harmonic Column Geometry**:
  - Increase `barWidth` to 20px–24px with smooth pill caps (`rx="6"`).
  - Ensure column bars occupy 50–55% of each slot width, eliminating the 70% dead whitespace.
  - Suppress the distorted 3px red sliver when realized revenue is zero; show an honest baseline marker and display `"₹ 0"` in the hover scrubber.

#### Phase 4: Master Commercial Deals Ledger Remediation
- **Fix Missing `.srOnly` CSS Bug**:
  - Add `.srOnly` to `CommercialDealsLedger.module.scss`:
    ```scss
    .srOnly {
      position: absolute;
      width: 1px;
      height: 1px;
      padding: 0;
      margin: -1px;
      overflow: hidden;
      clip: rect(0, 0, 0, 0);
      white-space: nowrap;
      border: 0;
    }
    ```
- **Pipeline Deals vs. Follow-up Tasks Separation**:
  - Surface active pipeline deals in the ledger rather than only overdue tasks.
  - De-escalate urgency tags: quiet neutral text for active deals (`In cadence`, `Updated 2d ago`); reserve amber (`Due today`) and muted rose (`SLA Alert`) strictly for real action items.
  - Change `Negotiation` stage color from danger red (`#ea002a`) to executive obsidian (`#111111`).
- **Continuous Segmented Progress Pips**:
  - Replace typewriter dashes with a continuous 64px segmented progress bar with hairline dividers.
- **Streamlined Row Actions**:
  - Remove duplicate `↗` icon buttons; make row click navigate to dossier, and use a refined ghost `Advance` trigger on hover.
- **Deterministic Luxury Monograms**:
  - Map client monograms to curated mineral pastel backgrounds (Sage `#eef4f0`, Taupe `#f6f3ee`, Slate `#f1f3f7`).
